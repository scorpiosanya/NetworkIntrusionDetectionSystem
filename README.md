A Machine Learning-based project to detect and classify malicious network activity using supervised learning algorithms. This project demonstrates the application of various classification models for cyber threat detection and includes a real-time prediction interface using Flask and a frontend web form.

Features
Preprocessed and cleaned NSL-KDD dataset

Feature selection using Mutual Information and correlation

Trained multiple ML models: KNN, SVM, Decision Tree, Random Forest, AdaBoost, Gradient Boosting, XGBoost, LightGBM

Hyperparameter tuning using Optuna

Ensemble learning via Voting Classifier

Flask-based API for real-time predictions

Simple HTML + JavaScript frontend for user input and result display


Models Used
✅ K-Nearest Neighbors (KNN)

✅ Support Vector Machine (SVM)

✅ Decision Tree

✅ Random Forest

✅ Gradient Boosting

✅ XGBoost

✅ LightGBM

✅ AdaBoost

✅ Voting Classifier (Ensemble)
